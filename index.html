https://w3id.org/sanskrit-lexicon/

Permanent identifier namespace for Linked Open Data derived from the Cologne Digital Sanskrit Dictionaries.

Status: namespace registered, graph data not yet published. The IRI scheme below is stable and in use by the generator and its test fixtures. Instance data (entries, senses, citations) is withheld pending an editorial sense-approval gate — the current translation store is entirely machine-produced and has not been human-approved for publication. The SHACL profile is published now so the modelling contract can be reviewed and cited ahead of the data.

Schema published; data gated.
/pwg-ru/ Former name of the same namespace, retired 27-07-2026: four of its five graphs are not Russian, so the name claimed a property the namespace does not have. No identifier was withdrawn. Permanent 301 to /repwg/.

Slash IRIs are used for instances and resolve by 303 redirect with content negotiation (text/turtle → .ttl, otherwise HTML). The hash form is reserved for the pwglex: vocabulary document.
